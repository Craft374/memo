# MEMO (Windows)

바로 켜서 쓰는 아주 단순한 메모 앱의 윈도우 버전입니다.

Electron이 아닌 네이티브 WinForms(.NET 8) 앱이라 즉시 실행되고 즉시 종료됩니다.
원래 맥용으로 만든 앱을 포팅한 것으로, 맥 버전(Swift/AppKit)은 [`mac` 브랜치](https://github.com/Craft374/memo/tree/mac)에 있습니다.

## 빌드 & 실행

```powershell
.\build.ps1 -Run
```

- 빌드 결과물은 `build\MEMO.exe`
- 빌드하면 시작 메뉴에 `MEMO` 바로가기가 생깁니다 (검색 후 작업 표시줄 고정 가능)
- .NET SDK가 없으면 사용자 폴더에 자동으로 설치합니다 (관리자 권한 불필요)

## 기능

- Windows 네이티브 WinForms 앱 (Electron 아님 — 즉시 실행/종료)
- 다크모드 고정 (타이틀바 포함)
- 왼쪽 줄 번호
- 탭 메모 (2개 이상일 때만 탭 UI 표시, 부드러운 등장/퇴장 애니메이션)
- 탭별 자동 저장 (350ms 디바운스 + 창 전환/닫기 시 즉시 저장)
- 중복 실행 시 기존 창 활성화 (단일 인스턴스)
- 창 위치/크기 기억
- Ctrl + 마우스 휠 0.25pt 단위 글자 크기 조절
- 왼쪽/가운데/오른쪽 정렬 (문단 단위, 저장 유지)
- 탭 x 버튼·마우스 휠 클릭으로 탭 닫기, + 버튼으로 새 탭
- 긴 줄이 화면에서 접혀도 줄번호는 증가하지 않음
- 웹/트위터 복사 붙여넣기 시 서식 제거
- 자동 줄바꿈 켜기/끄기

## 단축키

- `Ctrl + T` 또는 `Ctrl + D`: 새 탭
- `Ctrl + W`: 현재 탭 닫기
- `Ctrl + Tab` / `Ctrl + Shift + Tab`: 다음/이전 탭 (`Ctrl + ]` / `Ctrl + [` 도 가능)
- `Ctrl + S`: 지금 저장
- `Ctrl + L` / `Ctrl + E` / `Ctrl + R`: 왼쪽/가운데/오른쪽 정렬
- `Ctrl + +` / `Ctrl + -` / `Ctrl + 0`: 글자 크게/작게/초기화
- `Ctrl + Alt + W`: 자동 줄바꿈 켜기/끄기

## 사용 기술

- C# / WinForms (.NET 8)
- 외부 패키지·네트워크 접근 없음

## 참고

- 메모는 `%APPDATA%\MEMO` 안에 자동 저장됩니다.
- 탭 목록은 `tabs.json`, 탭 내용은 `tabs` 폴더 안에 저장됩니다 (맥 버전과 동일한 형식).
- 각 탭은 정렬 저장용 `.rtf`와 일반 텍스트 백업용 `.txt`를 같이 만듭니다.
- 글자 크기·자동 줄바꿈·창 위치는 `settings.json`에 저장됩니다.
